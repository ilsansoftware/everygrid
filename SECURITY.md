# Security Policy

## Supported versions

Only the latest release of `@everygrid/grid` on npm receives security fixes.

## Reporting a vulnerability

Please don't open a public issue. Use
[Report a vulnerability](https://github.com/ilsansoftware/everygrid/security/advisories/new)
on GitHub to send a private report.

Include the affected version, what an attacker can do, and the steps or a config to reproduce it.
We will acknowledge the report and keep you posted until it is fixed.
